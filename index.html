Tools

Built for an engagement. Kept after it.

No wrappers around a scanner. Each of these does one job properly, on the hardware it has to run on.

wifikit

MVP

WiFi pentesting toolkit for macOS and Linux. Scanner, ten attack engines, packet capture and handshake export in a single binary — no kernel extensions, no VM.

Rust MIT CLI

agentic-inbox

Fork

A community fork of Cloudflare's self-hosted AI email client, kept working after upstream went quiet. Live model defaults, envelope-based routing, MCP tools that provision a mailbox on demand.

TypeScript Apache-2.0 Workers
